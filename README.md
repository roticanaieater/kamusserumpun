**Kamus Serumpun** is a dictionary-inspired website designed in an interactive way, where users get to choose 2 to 3 Nusantara languages to compare. Some of the languages are divided further into dialects, and language level (like Javanese being mainly divided between <i>ngoko</i> and <i>krama</i>).

As the entry of words here are mostly based on published literary materials rather than interviews with native speakers, each language chosen will have their sources listed in the bibliography above the footer section. Therefore, a report box is available for native speakers to correct the words listed here whenever they spot an error in this website.

In current development, the entry of words will be limited to the 207 Swadesh list of words. Once this website that's currently in development has been perfectly completed, more entry of words will be added later.

## ✨ Features

* **Interactive map:** Languages are primarily picked through the map that shows the areas where each language is spoken. Users are able to zoom in or enlarge the map to see small details better.
* **Dialects Availability:** Visitors not only can compare the standard version of the language to another. As languages are naturally divided into dialects whereas each dialect can differ each other despite being in the same language root, users can choose which dialect to compare.
* **Two Modes of Display:** The entry of words can be set to be displayed in two different ways, either with pictures making it a picture-dictionary-like design with visualisation, or a simple comparison table.
* **Accuracy Critique Box:** A box form will always be shown on the screen for native speakers of each language to report errors or even provide better translations.
